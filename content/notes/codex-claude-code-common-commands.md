## 摘要

作者觀察到大多數人用 Codex 和 Claude Code 時，翻來覆去就是那幾句最基本的指令——「continue」「fix this」「try again」，其實這兩個工具還有更多值得善用的進階指令。原文把常用指令整理成兩張圖分享（圖片內容未能抓取，僅存連結）。

## 重點

- 核心提醒：不要停在最陽春的迭代式提示（`continue` / `fix this` / `try again`），這只是把 AI 當「再試一次」按鈕，沒發揮工具的能力。
- 進階用法的方向（可自行對照官方指令）：明確給脈絡與目標、要求先解釋計畫再動手、要求跑測試/驗證、指定要改哪個檔案與範圍，而非泛泛地說「修一下」。

## 個人洞見

跟 [[claude-code-github-repos-limitations|補足 Claude Code 短板的專案]] 是同一個方向的思考——工具的天花板往往不在模型，而在使用者會不會下指令。與其反覆 `try again`，不如把要求講清楚（脈絡、範圍、驗證方式），這其實就是 context 工程的日常實踐。可再參考 [[ten-claude-skills-research-writing-coding|十個 Claude 技能]] 擴充自己的指令庫。
