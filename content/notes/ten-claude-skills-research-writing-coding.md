## 摘要

作者 gitmindtw 整理了十個橫跨研究、寫作、寫程式三種工作流的 Claude Skills（可掛在 Claude Code / Agent 上的技能模組）。每個 skill 對應一個具體場景，從去除 AI 味、產生視覺草稿、寫論文，到即時跑資料、爬網頁、被 AI 反問挑戰，涵蓋知識工作者的日常。

## 重點

- `humanizer`：去除文字的 AI 特徵，讓輸出讀起來更自然、更像人寫的
- `claude-design` / `sketch`：從概念快速生成視覺草稿
- `research-paper-writing`：產出有結構的學術論文初稿
- `jupyter-live-kernel`：即時執行資料與視覺化（接上 Jupyter kernel 跑程式）
- `writing-plans` / `plan`：把複雜的寫作任務拆解成步驟與時程
- `powerpoint`：快速產生專業簡報素材
- `popular-web-designs`：追蹤當前流行的網頁設計模式
- `arxiv`：快速搜尋與追蹤最新的 arXiv 研究論文
- `firecrawl`：高效爬取並結構化網頁資料
- `grill-me`：對你的方案給出嚴格反饋、反覆質問，把想法磨得更紮實

## 個人洞見

這些 skill 的共通邏輯是「一個場景一個模組」，把泛用 agent 收斂成專用工具。其中 `humanizer` 跟我收過的 [[im-human-humanize-ai-writing|I'm Human 去 AI 味]] 是同一路思路；`grill-me` 則是刻意用 AI 當對手來壓力測試想法，跟 [[eli5-explain-like-im-five-tool|ELI5 工具]] 一樣屬於「用 AI 換角度」的技巧。值得挑幾個裝進自己的 Claude Code 工作流試用。
