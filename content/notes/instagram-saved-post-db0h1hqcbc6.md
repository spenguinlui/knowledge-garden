## 摘要

jasonxtsai 的 7 張輪播貼文，主張真正卡住 Claude Code 使用者的不是模型能力，而是周邊工作流的缺口。他點出四個常見痛點——不能看影片、跨 session 沒記憶、前端產出同質化、愛多寫程式碼——並各推一個安裝不到三分鐘的 GitHub repo 補齊，號稱能解掉 95% 的問題。留言區大量以「REPO」索取清單。

## 重點

- 主打文案：**「5 個 GitHub repo 解決 95% Claude Code 的問題」**，每個安裝不到三分鐘、裝完就有感。
- 痛點一 **看不了影片**：Claude Code 原生無法讀影片內容，需要外掛把影片轉成可讀的文字/截圖脈絡。
- 痛點二 **每開新 session 就重讀專案**：缺跨 session 記憶/專案索引，每次都要重建 context。
- 痛點三 **前端全部長一樣**：預設產出介面同質化嚴重（AI slop），需設計規範或風格注入。
- 痛點四 **自己多寫兩百行沒要的程式碼**：模型傾向過度實作，需約束讓它只做被要求的事。
- 作者提供一份文件，含各 repo 的安裝步驟、使用情境與免費 skills；貼文互動高（641 讚、637 留言）。

## 個人洞見

這則跟同一貼文更完整的整理 [[claude-code-five-repos-fix-limitations|五個 repo 補齊 Claude Code 短板]] 是同一條脈絡，也呼應 [[claude-code-github-repos-limitations|Claude Code 的既知限制]]。核心觀點值得記：把 agent 的短板當成可外掛補齊的模組，而不是等官方。前端同質化那點對得上 [[design-skills-fix-ai-slop-web-design|用設計技能修 AI slop]]。實際要落地仍需回頭補上五個 repo 的具體名稱。
